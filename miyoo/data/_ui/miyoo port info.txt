# The Port info page (main menu, Miyoo Mini Plus). Command names in <angle brackets>
# become the buttons that send them, so this stays right if the controls change.

help "miyoo port info"
	`This is the full Endless Sky (same story, ships and missions), with a renderer, screen layouts and controls made for the Miyoo Mini Plus. Saves go to Saves/CurrentProfile/saves/EndlessSky on the SD card; the game saves whenever you land, as the original does.`
	`FLYING`
	`Steer with <Turn left> and <Turn right>, thrust with <Forward thrust>, reverse with <Reverse>. Fire with <Fire primary weapon> and <Fire secondary weapon>, boost with <Fire afterburner>. Target the nearest enemy with <Select nearest hostile ship>. Land with <Land on planet / station>, jump with <Initiate hyperspace jump>, open the map with <View star map>, board with <Board selected ship>. <Show main menu> opens the main menu.`
	`HOLD SELECT FOR MORE`
	`Hail: <Talk to selected ship>. Next ship: <Select next ship>. Switch secondary weapon: <Select secondary weapon>. Fighters: <Deploy / recall fighters>. Scan: <Scan selected ship>. Auto steer: <Auto steer>. Messages: <View message log>. Nearest asteroid: <Select nearest asteroid>. Fleet orders: <Fleet: Fight my target>, <Fleet: Gather around me>, <Fleet: Hold position>, <Fleet: Toggle hold fire>.`
	`HOLD START FOR MORE`
	`Player info: <View player info>. Cloak: <Toggle cloaking device>. Fleet harvest: <Fleet: Harvest flotsam>. Fleet ammo: <Fleet: Toggle ammo usage>. Pause: <Pause>. Help: <Show help>. Fast-forward: <Toggle fast-forward>. Fleet jump: <Initiate fleet jump>. Fleet scan: <Fleet: Scan my target>. Turret tracking: <Toggle turret tracking>.`
	`POINTER (MENUS AND PLANETS)`
	`Tap Select to switch between flying and the pointer; landing and taking off switch for you. The D-pad jumps the pointer from button to button and row to row (outlined in orange; hold to keep going). On the map, or where there is nothing more that way, it moves freely instead (a tap nudges it, holding speeds up). A clicks, X right-clicks, B goes back, Start confirms. L1 and R1 scroll, L2 and R2 page up and down, and Select with the D-pad sends arrow keys. Hold Select or Start while clicking to buy or sell 5 or 20 at once (both together: 100), or to add ships to a selection. Start with B centres the map on your system.`
	`TYPING`
	`A keyboard appears whenever the game asks for text (pilot name, renaming a ship, searching the map). The D-pad picks a key, A types it, B deletes, X is Shift, Start is done, L2 and R2 scroll the text behind, and Y hides the keyboard. In pointer mode, Y brings it back.`
	`MENU BUTTON AND ONION`
	`Menu leaves for Onion's game switcher. On a planet the game saves first; in flight progress since you last landed would be lost, so it asks for a second press. When the battery is almost flat (Onion's own setting, 4% at first) the game saves on a planet and hands over to Onion, which powers off. Asleep (Power), the game stops where it is; on waking in flight the main menu opens, so nothing hits you before you look.`
	`TIPS`
	`The bar at the top right shows the time, Wi-Fi and battery. Preferences, Settings, "Show frame rate" adds a frame counter at the top left. Texture filtering (smoother sprites) and motion blur look nicer but cost speed; both are in Preferences, Settings, and start off. Every control is listed in Preferences, Controls.`
	`MINI PLUS SETTINGS`
	`Preferences, Settings, last page: "D-pad jumps between buttons" (off for a free pointer everywhere), "Button hints" (hold Select or Start for a moment to see what each button does), "Rumble" (off, light or strong: hits, shields failing, jumps), "Battery saver" (fewer frames and a slower CPU on planets and menus; flight is unchanged), "Start in last save" (skip the main menu and go straight to your ship), and "Stay awake in flight" (keeps Onion's sleep timer from stopping a long autopilot trip). "UI font size" 18 makes conversations, mission and planet text larger. The battery warns at 15% and 5%.`
